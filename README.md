# 象数工坊

一个完全离线的传统历法推算工具。**双击就能用，不用安装、不用联网、不上传任何数据。**

支持七个模块：四柱历法 · 卦象推演 · 六爻纳甲 · 小六壬 · 时辰规则引擎 · 合盘计算 · 口径说明。

---

## 立即使用

### 方式一：下载单文件版（推荐，不用懂技术）

1. 打开 [Releases](https://github.com/xiangshu2026/xiangshu/releases) 页面
2. 下载 `xiangshu-1.0.0.html`
3. **双击打开**，浏览器会自动显示界面

手机上也能用：把文件传到手机，用浏览器打开即可。

### 方式二：在线使用

直接访问：**https://xiangshu2026.github.io/xiangshu/**

> 国内访问 GitHub Pages 有时不稳定，打不开就换方式一。

### 方式三：下载完整版

1. 点页面右上角绿色 `Code` 按钮 → `Download ZIP`
2. 解压到任意文件夹
3. 双击 `启动.bat`

## 它是什么

**历法算法与规则推演的技术实现**，用于传统文化研究与算法实践。

技术内核：干支推算 · 节气定位 · 真太阳时校正 · 藏干加权 · 地支关系矩阵（冲/合/刑/害/破/伏吟/成局）· 基于传统文献的规则计分体系。

> ⚠️ **定位说明**：本项目**不提供任何形式的预测服务或命运判断**。所有输出均为规则计算结果，仅供技术研究与个人参考。

## 七个模块

| 模块 | 做什么 |
|---|---|
| **四柱历法** | 年月日时干支、十神、藏干、纳音、神煞、空亡、大运流年、真太阳时校正 |
| **卦象推演** | 时间/数字起卦、体用、互卦、变卦、综合断 |
| **六爻纳甲** | 京房八宫、世应、六亲、六神、旺衰 |
| **小六壬** | 数字/时间起课、六神断 |
| **时辰规则引擎** | 十二时辰计分、卡池档期计算、记录与概率（娱乐向） |
| **合盘计算** | 两种命盘的关系矩阵计算（完整盘/月令盘/五行简盘） |
| **口径说明** | 全部计算依据公开 |

每个模块的完整说明、输入边界、算法口径见 [docs/功能详解.md](docs/功能详解.md)。

## 常见问题

**需要联网吗？**
不需要。所有计算在你自己的电脑/手机上完成，不上传任何数据。

**需要安装 Python / Node.js 吗？**
用单文件版完全不需要。只有想改代码、跑测试时才需要 Node.js。

**我填的生日会被上传吗？**
不会。数据只存在你浏览器的本地存储里，断网也能用。

**手机能用吗？**
能。用单文件版或在线地址都可以。

**怎么卸载？**
删掉文件就没了，没有残留。

## 开发者信息

**技术栈**：纯前端，原生 JavaScript（UMD 双环境，浏览器与 Node 共用同一份代码），无框架无构建依赖。

**测试**：424 项自动化测试，覆盖官方历法用例、古籍卦例、京房八宫全表。

```bash
npm test          # 跑全部测试
npm run build     # 重新打包单文件版
```

**历法底座**：[6tail/lunar-javascript](https://github.com/6tail/lunar-javascript) 1.7.7（MIT）——四柱、节气、大运、藏干、十神、纳音均为其天文算法结果。六爻/梅花/小六壬逻辑、易学数据与界面为自研。

**目录结构**：

```
├── index.html          单页应用骨架
├── 启动.bat            双击启动
├── assets/             样式与图标
├── js/                 17 个模块（16 自研 + lunar.js）
├── tests/              run-all.cjs（424 项断言）
├── tools/              打包 / 图标 / 快捷方式
├── vendor/             第三方许可
└── docs/               功能详解、开发实录、简历说明
```

更多开发细节见 [docs/开发实录.md](docs/开发实录.md)。
