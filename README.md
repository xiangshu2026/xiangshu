## 它是什么

**历法算法与规则推演的技术实现**，用于传统文化研究与算法实践。

技术内核：干支推算 · 节气定位 · 真太阳时校正 · 藏干加权 · 地支关系矩阵（冲/合/刑/害/破/伏吟/成局）· 基于传统文献的规则计分体系。

> ⚠️ **定位说明**：本项目**不提供任何形式的预测服务或命运判断**。所有输出均为规则计算结果，仅供技术研究与个人参考。

## 使用边界与算法口径

### 输入边界与容错（已自测）

| 场景 | 行为 |
|---|---|
| 农历选了该年不存在的闰月（如 2020 闰六月） | 中文提示「农历 2020 年没有闰六月（该年不存在这个月，请核对闰月设置）」 |
| 农历日期超出当月天数（如腊月三十但只有 29 天） | 中文提示「只有 29 天，请改到 1~29 之间」 |
| 八字空日期 | 提示排盘失败，页面不崩 |
| 小六壬输入 0 / 负数 | 不崩，按 1 计并在提示里说明 |
| 梅花数字留空 | 按 0 取余正常出卦（不会 0 卦/NaN） |
| 卡池结束日早于开始日 | 提示「结束日期不能早于开始日期」 |
| 卡池跨度 > 180 天 | 只算前 180 天并在结果里标注 |
| 卡池已结束 / 未开始 | 分别给出「已结束，以下为历史区间参考」/「N 天后开启」 |
| 相性缺角色信息 / 缺我的生日 | 分别给出对应中文提示 |
| 记录页切换游戏 | 与主游戏双向同步，统计与概率块跟着切换 |

### 相性分怎么算（为什么不是人人 90 分）

**分数按各档位的理论可达区间归一，不是硬套一条及格线**：
- **50 分 = 中性**（各项合计为 0，即"不好不坏"）
- **100 分 = 该档位理论满分**（各项都拿到上限）
- 各档位分量不同，所以**满分也按信息量封顶**：
  | 档位 | 能比的项 | 理论区间 | 满分 |
  |---|---|---|---|
  | 完整盘（有年份） | 日主、日支合冲、日干五合、喜用、五行互补、年支 | −60 ~ +92 | **100** |
  | 月令盘（只知月/日） | 日主×月令、月令合冲、喜用、补缺 | −28 ~ +31 | **88** |
  | 五行简盘（只有属性） | 日主×属性、喜用、补缺 | −26 ~ +38 | **80** |
- **档位等级线统一**：≥88 天作之合 / ≥76 相得益彰 / ≥62 平顺相处 / ≥46 需要磨合 / 其余八字相冲
- 所以「月令盘 79 分 = 相得益彰」已经是**该资料下的高分**；想拿 88+ 必须补上角色的完整生日（含年份）

**为什么同一档位内分数容易扎堆**：月令盘只比 2 个计分项（日主生克 ±10、月令合冲 ±14），可能的分数就那几档，所以 79 分并列常见——这不是算法偷懒，是"只有月日"这种资料本身的信息量上限。**资料越全，分差才拉得开。**

### 算法口径（重要）

工具把判断依据全部列在界面上，方便自己核对；**不做命运保证，结论请以自己取象为准**。

- **月柱以「节」为界**（立春、惊蛰…小寒），不是农历初一。节气时刻由内置历法库按天文算法计算，精确到秒。
- **日柱换日**：默认晚子时（23:00 后）算次日。
- **五行计分**：天干 1.0／字；地支按藏干本气·中气·余气比例折算，月支 ×1.5。
- **旺衰**：同党（比劫＋印）／异党（食伤＋财＋官杀）比值 ≥60% 偏强、≤40% 偏弱，其余中和——属简法。
- **六爻纳甲**依古歌：乾甲子外壬午、坎戊寅外戊申、艮丙辰外丙戌、震庚子外庚午、巽辛丑外辛未、离己卯外己酉、坤乙未外癸丑、兑丁巳外丁亥。
- **变爻六亲双标**：古书与各家软件口径不一，本工具并列显示，可按所宗之书取用。
- 详细口径见软件内 **「说明与口径」** 模块，逐条写明公式与取法。

## 常见问题

**需要联网吗？**
不需要。所有计算在你自己的电脑/手机上完成，不上传任何数据。

**需要安装 Python / Node.js 吗？**
用单文件版完全不需要。只有想改代码、跑测试时才需要 Node.js。

**我填的生日会被上传吗？**
不会。数据只存在你浏览器的本地存储里，断网也能用。

**手机能用吗？**
能。用单文件版或在线地址都可以。

**怎么卸载？**
删掉文件就没了，没有残留。

## 开发者信息

**技术栈**：纯前端，原生 JavaScript（UMD 双环境，浏览器与 Node 共用同一份代码），无框架无构建依赖。

**测试**：424 项自动化测试，覆盖官方历法用例、古籍卦例、京房八宫全表。

```bash
npm test          # 跑全部测试
npm run build     # 重新打包单文件版
```

**历法底座**：[6tail/lunar-javascript](https://github.com/6tail/lunar-javascript) 1.7.7（MIT）——四柱、节气、大运、藏干、十神、纳音均为其天文算法结果。六爻/梅花/小六壬逻辑、易学数据与界面为自研。

**目录结构**：

```
├── index.html          单页应用骨架
├── 启动.bat            双击启动
├── assets/             样式与图标
├── js/                 17 个模块（16 自研 + lunar.js）
├── tests/              run-all.cjs（424 项断言）
├── tools/              打包 / 图标 / 快捷方式
└── vendor/             第三方许可
```
