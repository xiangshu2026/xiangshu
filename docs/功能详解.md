# 功能详解

> 本文档说明七个模块的完整功能、输入边界与算法口径。
> 返回使用说明：[README.md](../README.md)

一套**纯本地、离线可用**的传统历法推算工具。无需安装、无需联网、不上传任何数据，双击即用。

---


## 一、界面：首页选模块，点进去只看该模块

打开后先看到**首页**（7 张卡片：生辰八字 / 梅花易数 / 六爻纳甲 / 小六壬 / 抽卡时运 / 二次元相性 / 说明与口径）。
点一张卡片进入该模块，左上角「← 返回首页」随时退出。

**抽卡时运再往里分 5 个子模块**（点进去只看那一块，左上角「← 返回抽卡时运」退回）：
1. **今日时运** — 判档 + 最好/最差时辰 + 此刻抽卡（时运×概率）+ 签文 + 时辰表
2. **最近最宜 & 一周走势** — 未来 30 天最宜日 + 7 天柱状走势
3. **卡池档期 · 哪天抽最好** — 填起止日期，逐日算最宜/避开
4. **抽卡记录 & 十连概率** — 记一笔 + 连歪计数器 + 保底进度 + 下一发十连出卡概率
5. **术语小抄** — 每个名词一句人话

## 三、六个模块能做什么

### 1. 生辰八字
- **四柱**：年月日时干支、十神、地支藏干（含藏干十神）、纳音、地势（长生十二宫）、旬空
- **历法**：公历／农历双输入（支持闰月）、生肖、星座、所处节气
- **真太阳时**：按出生地经度校正（均时差 + 经度差），适合出生时辰卡在边界的情况
- **日柱换日流派**：晚子时算次日／算当日，一键切换
- **五行力量**：天干地支按藏干比例加权计分 + 柱状图 + 缺五行提示
- **账号名称**：可填昵称/账号名（代替人名），显示在结果标题与导出的文本里，填一次全站同步
- **旺衰取用**：得令／得地／得势 + 同党异党比值 + 取用倾向（扶抑简法）
- **神煞**：天乙贵人、文昌、禄神、羊刃、驿马、桃花、将星、华盖、孤辰寡宿、红艳、金舆、魁罡、月德天德、旬空
- **大运流年**：起运时间（精确到年月日）、八步大运、点击大运展开该运十年流年（自动高亮当年）
- **胎元／胎息／命宫／身宫**

### 2. 梅花易数
- **起卦法**：时间起卦（农历年月日时）、数字起卦（两数／三数）、文字起卦（字数）、随机起卦、直接选卦
- **卦象**：本卦／互卦／变卦三卦并排，动爻用 ○ 标记
- **体用**：动爻所在为用、另一为体；用生体／体克用／比和为吉、体生用为泄、用克体为凶
- **月令旺衰**：旺相休囚死 + 体卦变卦对照
- **断语**：逐条给出推断依据（体用、生克、过程、结果、卦体），并给综合倾向
- **取象与应期参考**：八卦万物类象 + 用卦先天数与五行取时

### 3. 六爻纳甲
- **摇卦**：三枚铜钱（背=3／正=2），逐爻摇、可一键随机、可手动指定六爻、可数字起卦
- **装卦**：京房八宫归属（六世／一世～五世／游魂／归魂）、世应、纳甲干支、六亲、六神（按日干起）
- **伏神**：六亲不上卦时于本宫首卦同爻位寻取
- **日月**：月建、日辰、旬空（自动标空亡爻）
- **变卦**：动爻阴阳互变、变爻纳甲六亲（**同时给"对本宫"与"对变卦宫"两种口径**）
- **卦体**：六冲卦／六合卦／反吟／伏吟／三合参考、进神退神、回头生克、化空
- **用神分析**：按事类定用神，输出用神旺衰、旬空、与世应关系、原神／忌神／仇神

### 4. 小六壬
- 月日时起课（大安起正月、月上起日、日上起时）／三数报数／随机
- 六宫掌诀全文、宫义、宜忌、求财／疾病／行人／失物分项断语
- 六宫全图高亮落宫

### 5. 今日抽卡时运（娱乐向 · 规则优先，不调参）
**判档走传统择日规则，不是拿分数切出来的：**
1. **值神**：十二值神分黄道（青龙/明堂/金匮/天德/玉堂/司命）与黑道（天刑/朱雀/白虎/天牢/玄武/勾陈）
2. **建除十二神**：「建满平收黑，除危定执黄，成开皆可用，闭破不相当」
3. **吉神凶煞**：数量对比
4. **合判**：黄道＋建除成开＋吉神≥凶煞 → **大吉**；黑道＋破/闭 → **大凶**；吉凶相抵 → **平**
5. **封顶与降档**：破日封顶为凶、闭日封顶为平（诸事不宜）；今日日支冲你的日支 → 按「日辰冲命」**降一档**
- **气势分**（0~100）＝ 50 ＋ 合计 × 3.0，是规则的透明汇总，**档位由它决定**（两者永远一致）、不是出货率预测；每一项的计分与传统依据都列在结果里
- **十二时辰吉凶**：每个时辰按自己的值神黄道/黑道判，与传统黄历一致
- **最近最宜抽卡日期**：未来 30 天逐日判档后排名（档位优先 → 气势分 → 日期近），给出最宜日、次选 2 天、要避开的最差日；最佳日附最佳时辰
- **最近一周走势**：今天起 7 天的柱状图（绿吉红凶、今天高亮）+ 本周走高/走低/平稳、最高日与最低日
- **本期卡池 · 哪天抽最好**：填卡池起止日期，逐日扫描**剩余每一天**，给出区间最宜日（含时辰/建除）、避开日、次选、档位分布、逐日色带；并直接比较今天与最佳日给出「今天先别抽，等到 X 月 X 日」这类结论（跨度 >180 天只算前 180 天）
- **游戏专属签池**：当前收录 **明日方舟 / FGO / 绝区零 / 碧蓝航线 / 其他游戏**（其他游戏用通用签池），各用自己的术语（六星、合成玉、圣晶石、呼符、五星从者、菲林、S 级、UR、建造…）；签文由确定性哈希选取，同一天不变。要加新游戏，在 `js/xs-games.js` 的 GAMES 里追加一项（含五档签池与保底参数）即可
- **抽卡记录 · 连歪计数器**：记录本机保存，自动算总抽数、出货率、**连歪次数**、**距上次出货**、**距保底**（按各游戏保底参数），并分游戏汇总
- **每日一句待办提醒**：打开页面自动生成（连歪≥3 → 提醒停手；保底≤10抽 → 提醒补保底；大吉 → 提醒挑吉时；凶/大凶 → 提醒攒票），可勾选「今日已完成」；下面还带一行「最好抽 / 最差」时辰
- **抽卡时间建议（明写）**：结果里有独立的「今天什么时候抽最好」卡——**最好**列今日吉时（十二时辰里分数最高的黄道时辰，可能 2~3 个），**最差**取全十二时辰最低分（必为黑道时辰），各带时间区间、值神与分数，并配一句话总结
- **下一发十连出卡概率（纯数学）**：在「抽卡记录」折叠区里，按游戏公示概率 + 当前累计未出货抽数，算出十连至少出一个的概率、逐抽概率柱状图、概率态势分（基准十连概率=50、保底必出=100）；参数可改并本机保存。**与运势无关**
- **此刻抽卡（时运 × 概率）**：结果里给出三宫格——今日时运分 / 概率态势分 / **综合抽卡分（各占 50%）**，并给一句建议。档位仍只由传统规则判定，概率分只进综合分
- **换游戏/换账号会即时重算**：档位与气势分只由当日历法决定（换游戏、换账号都不变）；游戏只决定签池，账号只决定签文
- **签文按账号定**：以「日期＋账号＋游戏」哈希取签，同一账号同一天固定，换账号或换游戏即换签
- **账号名称**：用昵称/账号名代替真实人名，填一次两页同步、存本机；会出现在排盘标题、待办提醒、抽卡记录与导出的 TXT 里
- 坦白说明：抽卡结果由游戏官方概率决定，术数改不了它；请设预算、量力而行
- **不做「调参让分布好看」**：凶日多、大吉少本来就是传统择日常态，本工具不改权重也不改阈值去迎合观感

### 6. 二次元相性（娱乐向）
- **方法**：按传统**合盘（合婚/合盘）**规则比对双方八字——日主五行生克、日支（夫妻宫）六合/三合/六冲、日干五合、日柱天克地冲、喜用神互补、五行互补（你缺的是他旺的）、年支六合/六冲
- **相性分 = 50 ＋ 各项合计**，每项分值固定且逐条列在结果表里（含"为什么这么算"的传统依据）；等级按分数固定区间（天作之合/相得益彰/平顺相处/需要磨合/八字相冲）
- **三档输入（知道多少算多少）**：
  1. **完整生日（含年份）** → 完整合盘（项目最全：日主、日支合冲、日干五合、喜用/五行互补）
  2. **只知道月/日**（大多数游戏角色是这种）→ **月令盘**：用节气月定「月令」，这是八字里最重的一层（先天气质/底色）；可算日主生克、月令合冲（与我的月支）、喜忌、补缺；生日紧贴节气交界（±1 天，年份不同会变）会自动提示「可能是 X 月或 Y 月」
  3. **连月日都不知道** → 只选**属性**（原神神之眼 / FGO 属性 / 方舟职业印象）→ **五行简盘**：自动换算五行（风雷草→木、冰暗→水、光电→火、岩→土、金→金），并给出十神关系、类象性格、喜忌、补缺
- **内置角色名单（79 名，仅女性）**：绝区零 **41**（全量女性代理人）/ 原神 12 / 崩坏：星穹铁道 10 / FGO 8 / 明日方舟 8
  - 每个角色带 **属性 → 五行、生日（月/日）、特性**，点名字自动填入表单（属性与生日源自游戏官方设定，2026-10 经萌娘百科逐条核对）
  - 游戏分类可切换、支持搜索；FGO 等无官方生日的角色只填属性 → 自动走五行简盘
  - **「假定年份」开关**（默认关）：角色没有真实年份时，可指定按 2026 年排出完整八字 → 走完整合盘、项目最全、分数拉得开。**年份是假设的**：同一角色换个年份，日柱就变、结论可能整档反转（实测 2026 vs 月令盘，70 个角色里 44 个结论变化、最大跳动 80 分；假定年份下年柱全体相同，年支已不计分）。适合当“如果 TA 生在这一年”的对照玩法，不适合当结论
  - 新属性已全部支持：物理→金（约定）、以太→土（约定）、玄墨→水（约定）、凛刃→金（约定）、流明→火（约定）、量子→水（约定）、盾→土（约定）、烈霜→水、风→木
  - 数据在 [js/xs-chars.js](js/xs-chars.js)，可直接改
- **角色库**：填一次「存到角色库」，之后点 chip 一键填回（生日/月日/属性都记住），存在本机；点 ✕ 删除
- 会自动带用八字页排过盘的"我的信息"；账号名称同步

### 7. 六爻纳甲怎么看（看不懂就看这两块）

六爻页信息密度最高，所以专门做了两个「看得懂」的模块：

**① 先看结论（置顶卡）**——用一句人话给粗判：
- 只判两件事：**你自己这一爻（世爻）有没有气**（月建/日辰是旺还是死囚）、**世应五行关系**（生我/我生/克我/我克/比和）
- 输出「吉 / 偏吉 / 平 / 偏凶 / 凶」+ 一句大白话 + 六冲六合的补充说明
- 明确标注这是**粗判**，要看细的往下读四步

**② 怎么看这张表（四步，人话版）**：
1. **先找「世」和「应」** —— 世＝你自己，应＝对方/环境；看五行关系判主动被动
2. **再看「六亲」** —— 父母＝文书房子证件长辈；兄弟＝同伴竞争也主破财；子孙＝平安解忧但克官；妻财＝钱财/女性；官鬼＝官职事业也主病与麻烦。**你问的事落在哪一类，那一爻就是「用神」**
3. **看「纳甲」和旺衰** —— 纳甲是这爻的干支五行，再看月建/日辰生它还是克它：旺＝有力，死/囚＝没劲。**事情成不成，主要看用神旺不旺**
4. **最后看「动爻」和「变卦」** —— 动爻少＝事情稳，多＝变数大；六冲主散、六合主合

**③ 装卦表本身**也改了：标题写明「完整排盘，看不懂可跳过」，表格上方说明这张表在讲什么，**每列表头悬停都有解释**（六神/伏神/六亲/纳甲/世应），并注明「新手只需关心六亲、纳甲、世应三列」。（抽卡时运页 →「卡池档期」子页）

填卡池起止日期 → 算**这期档期里你哪几天手气好**。**不是角色跟你合不合，也不是出货概率。**

| 输出 | 说明 |
|---|---|
| **整体运气** | 大吉/吉/平/凶/大凶，依据＝吉日占比 + 平均气势分（两个依据都公开） |
| **档位分布** | 档期内大吉/吉/平/凶/大凶各几天 |
| **最宜抽的几天** | 前 3 天，带**当天最好的时辰** |
| **最忌抽的几天** | 后 2 天，建议避开 |
| **档期内逐日** | 每天一行（星期/干支/值神/建除/档位/分数/最好时辰） |

判档规则：值神黄道/黑道 → 建除十二神 → 吉神凶煞 → 再叠加你的日干十神、今日之气是否合喜用、日支是否冲你日支。

**注意**：「运气」是日子本身的气场，**出货概率由游戏保底机制决定，和日期无关**（十连概率见「抽卡记录」子页）。

在「二次元相性」页最下方。**算的不是单个角色，是整期卡池跟你合不合**：

| 输出 | 说明 |
|---|---|
| **池子平均分** | 池内所有角色的相性分平均（月令盘满分 88 / 简盘满分 80） |
| **最合 / 最不合（各 3）** | 池里跟你最投缘、最不投缘的角色 |
| **池子五行偏向** | 池内角色属性分布，标出哪些是你的喜用 |
| **档期气运** | 用择日规则算卡池剩余天数，给出最宜/最忌的日子 |
| **池内逐人** | 全部角色按分排序，标档位（完整/月令/简盘） |

**注意**：相性说的是「这池角色的气场跟你合不合」，**不是「你能不能抽到」**——抽卡概率与运势无关（见抽卡页的十连概率）。

### 8. 白话解读（每个模块都有）
每次排盘后，**结果最底部会自动生成一张「白话解读」卡**，用大白话把盘讲一遍：
- **一句话结论**：先讲清"这盘到底说了啥"
- **分段解读**：
  - 八字 → 性格与做事风格 / 五行旺衰与调理方向 / 大运流年走势 / 命里几个明显标记
  - 梅花 → 眼前的处境（体用）/ 中间会经历什么（互卦）/ 最后会怎样（变卦）/ 时间点帮不帮你
  - 六爻 → 你与对方（世应）/ 所问之事的关键（用神）/ 变化在哪里（动爻变爻）/ 这一卦的气象
  - 小六壬 → 三步怎么数过来的 / 落宫是什么意思 / 分项看事
- **怎么用这些结论**：给出可执行建议，并明确标出哪些只是"倾向参考"
- 另外，**每个页面最底部常驻一份「术语小抄」**（可点标题折叠）：十神、藏干、纳音、地势、旬空、体用、互卦、世应、纳甲、六亲、六神、伏神、月建日辰、六冲六合……每个名词一句人话，不用另查资料。


## 四、输入边界与容错（已自测）

| 场景 | 行为 |
|---|---|
| 农历选了该年不存在的闰月（如 2020 闰六月） | 中文提示「农历 2020 年没有闰六月（该年不存在这个月，请核对闰月设置）」 |
| 农历日期超出当月天数（如腊月三十但只有 29 天） | 中文提示「只有 29 天，请改到 1~29 之间」 |
| 八字空日期 | 提示排盘失败，页面不崩 |
| 小六壬输入 0 / 负数 | 不崩，按 1 计并在提示里说明 |
| 梅花数字留空 | 按 0 取余正常出卦（不会 0 卦/NaN） |
| 卡池结束日早于开始日 | 提示「结束日期不能早于开始日期」 |
| 卡池跨度 > 180 天 | 只算前 180 天并在结果里标注 |
| 卡池已结束 / 未开始 | 分别给出「已结束，以下为历史区间参考」/「N 天后开启」 |
| 相性缺角色信息 / 缺我的生日 | 分别给出对应中文提示 |
| 记录页切换游戏 | 与主游戏双向同步，统计与概率块跟着切换 |

### 相性分怎么算（为什么不是人人 90 分）

**分数按各档位的理论可达区间归一，不是硬套一条及格线**：
- **50 分 = 中性**（各项合计为 0，即"不好不坏"）
- **100 分 = 该档位理论满分**（各项都拿到上限）
- 各档位分量不同，所以**满分也按信息量封顶**：
  | 档位 | 能比的项 | 理论区间 | 满分 |
  |---|---|---|---|
  | 完整盘（有年份） | 日主、日支合冲、日干五合、喜用、五行互补、年支 | −60 ~ +92 | **100** |
  | 月令盘（只知月/日） | 日主×月令、月令合冲、喜用、补缺 | −28 ~ +31 | **88** |
  | 五行简盘（只有属性） | 日主×属性、喜用、补缺 | −26 ~ +38 | **80** |
- **档位等级线统一**：≥88 天作之合 / ≥76 相得益彰 / ≥62 平顺相处 / ≥46 需要磨合 / 其余八字相冲
- 所以「月令盘 79 分 = 相得益彰」已经是**该资料下的高分**；想拿 88+ 必须补上角色的完整生日（含年份）

**为什么同一档位内分数容易扎堆**：月令盘只比 2 个计分项（日主生克 ±10、月令合冲 ±14），可能的分数就那几档，所以 79 分并列常见——这不是算法偷懒，是"只有月日"这种资料本身的信息量上限。**资料越全，分差才拉得开。**


## 五、抽卡时运的出生信息支持公历/农历 + 自动记忆

原来：抽卡页只有「出生日期（公历 date 框）+ 出生时间」，和八字页不一致——用农历生日的人没法填。

现在，抽卡页（抽卡时运 → 今日抽卡时运）的出生信息与八字页同款：

| 控件 | 说明 |
|---|---|
| 历法 | 公历（阳历）／农历（阴历）切换 |
| 出生日期 | 公历用日期框；农历用三个下拉（年 1900~2040 / 月 正月…腊月 / 日 初一…三十） |
| 是否闰月 | 勾选框，勾上即闰月 |
| 对应公历回显 | 选完农历立刻显示「对应公历：2004-08-13」，日期非法会提示 |
| 出生时间 | 可空（不填＝时辰未知，照样算） |
| 性别 | 男／女 |
| 出生地经度 | 可空，填了用于真太阳时 |

自动记忆：填一次就存进 localStorage（键 xiangshu.gacha.birth），下次打开自动带出历法、农历年月日、闰月、时间、性别、经度——不用重复填。

实测：9 项界面验证全过；记忆测试写入后重新打开页面，全部正确回填并回显「对应公历：2004-08-13」。


## 六、抽卡时运 与 八字当日运势 完全统一（同一天同分同档）

**原问题**：同一个日子，抽卡时运 说「吉」，八字当日运势 说「平」；还有「分数高的反而判平、分数低的反而判吉」。

**根因是四处口径不一致**（两个引擎各写了一套）：

| 项目 | 抽卡（旧） | 八字（新） |
|---|---|---|
| 十神权重 | ±1 | ±3 |
| 喜用权重 | ±1 | ±3 |
| 气势分系数 | ×4.5 | ×3.0 |
| 建除「破」 | −3 | −2 |
| 档位来源 | 规则判档（与分数脱节） | 分数决定 |
| 与命局其他柱相冲 | 缺这项 | 有 |

**统一后**：抽卡时运 与 八字当日运势 **同一天分数完全一致、档位完全一致**（实测 8 天 100% 对齐、30 天 0 差异）。

**同时修掉的**：
- 抽卡档位改为由气势分决定（解决「分数高反而平」）
- `dayBrief` 与 `todayLuck` 同口径（解决卡池扫描与单日结果不一致）
- 「与命局其他柱相冲」项补进抽卡（`makePersonal` 补传 `myYearZhi/myMonthZhi`）
- 所有「降一档」文案改为「冲命扣分」（档位由分数定，不存在降档概念）


## 七、梅花易数：结论更明显了（七档综合断）

**原来的问题**：梅花只按「体用生克」判档，只有 5 种结果（用生体/比和/体克用/体生用/用克体），而且比和永远判吉——所以多次起卦结论都差不多，看不出差别。

**现在**：按梅花易数正统断法做四层加权，输出七档：

| 层次 | 看什么 | 权重 |
|---|---|---|
| 体用生克 | 用生体 +6／比和 +3／体克用 +2／体生用 −3／用克体 −6 | 最重 |
| 体卦月令 | 旺 +2／相 +1.2／休 0／囚 −1.2／死 −2 | 次重 |
| 互卦（过程） | 用生体 +1.2／比和 +0.6／体克用 +0.4／体生用 −0.6／用克体 −1.2 | 中 |
| 变卦（结果） | 同体用权重 ×1.4 | 中 |

七档阈值（合计分）：≥8.5 大吉 / ≥5.5 吉 / ≥2.5 小吉 / ≥−2.0 中平 / ≥−4.5 小凶 / ≥−7.5 凶 / 其余 大凶。

实测 200 卦分布：大吉 9 / 吉 40 / 小吉 32 / 中平 62 / 小凶 28 / 凶 19 / 大凶 10 —— 七档都有，不再挤在「吉/中」。

界面上：结论卡置顶（大字号档位 + 综合分 + 刻度条），下面直接给「四层依据表」（层次/情况/含义/计分），每分都能追。


## 八、遇凶怎么避（化解建议）

八字页新增「遇到凶怎么避」卡。不是画符念咒，是按传统术数的趋避逻辑：先找凶在哪一维，再给对应调整。

| 层次 | 输出什么 |
|---|---|
| 一、五行偏枯 | 哪个五行占比 <10%（<4% 标「近缺」）→ 对应方位/颜色/生活习惯/该照顾的脏腑 |
| 二、喜用与忌神 | 喜用方位（大事安排在这边）、喜用颜色、忌神之日之方位少办大事 |
| 三、命带神煞 | 按神煞性质给行为规避（华盖→别钻牛角尖；空亡→签约易落空；驿马→少奔波…）；吉神单独列出，不算障碍 |
| 四、冲命之日 | 你的日支被哪一天冲击（如寅→申日）→ 那天避什么、适合做什么 |
| 五、具体某天 | 结合当日运势：判「凶·大」就建议推掉、必须办就挑吉时；黄历宜忌 |

底部固定提醒：避灾是调行为与节奏，不是改命；健康/法律/财务请以专业人士为准。


## 九、吉凶分「大 / 中 / 小」三档

原来的五档（大吉/吉/平/凶/大凶）粒度不够，现在吉和凶各自再分大中小：

| 细分 | 判定依据 |
|---|---|
| 吉·大 | 当日判大吉，或判吉且合计 ≥ +6 |
| 吉·中 | 判吉且合计 ≥ +2.5 |
| 吉·小 | 判吉但合计只略正 |
| 平 | 判平（不细分方向） |
| 凶·小 / 凶·中 / 凶·大 | 判凶时按合计 ≤ −2.5 / ≤ −6 对应（大凶直接记凶·大） |

实测 90 天自然分布：吉·大 7 / 吉·中 17 / 吉·小 5 / 平 29 / 凶·小 6 / 凶·中 13 / 凶·大 13。

显示位置：当日运势卡、未来 7 天列表、本月最佳榜、本月日历、遇凶避灾、卡池运气——全部跟着显示三档。


## 十、八字 · 当日运势（结合命盘看某一天）

八字页排完盘后，下方有「**看某一天的运势**」：选日期 → 点「看这一天」，用**你的命盘**去对那天的日辰。

**判档规则（规则式，不是分数阈值）**：
1. **值神黄道/黑道**（青龙明堂金匮天德玉堂司命＝黄道，余六＝黑道）
2. **建除十二神**（口诀「建满平收黑，除危定执黄，成开皆可用，闭破不相当」）
3. **吉神 / 凶煞数量对比**
4. **个人层**：日干十神（对你）、今日之气是否合你喜用、日支是否冲/合你日支、是否冲你年/月支、日支落旬空
5. **日辰冲你日支 → 降一档**（传统「日辰冲命」）

**输出**：档位 + 气势分 + 逐条依据表（项目/当日/含义/计分）+ 宜忌 + 对你说的话 + **十二时辰吉凶**（每个时辰的值神，标出最好/最差）+ 白话解读。
**四个快捷入口**：
- 「**今天**」一键看今天
- 「**未来 7 天**」7 天列表，**每行都可点开看详情**（带「详情 ›」入口、有返回按钮），并标出这几天里最好的一天
- 「**本月最佳**」：本月**最宜前 5** + **宜避后 3** + **整月日历热力图**（颜色＝档位：大吉深金 → 大凶深红）+ 档位分布统计；**榜上每一天、日历每一格都可点开看详情**
- 复制文本 / 导出 TXT

详情页复用同一套渲染（档位卡 + 这一天 + 逐条依据 + 宜忌 + 十二时辰 + 解读），点过的那天会缓存，来回切换不重复计算。

## 十二、时辰未知怎么处理（重要）

**出生时间一律默认留空**——不记得就别填，程序不会替你按正午/子时"假装知道"。

- 有空时间时：`hourKnown=false`，**时柱照算但标记为「未知」**，且**不参与身强身弱判断**（得地/得势里的时柱项不计入）
- **年柱、月柱、日柱完全不受时间影响**（日柱由日期定），所以不填时间照样能排盘、看十神、喜用、大运
- 结果里的「时辰」显示为「未填（不做时柱判断）」，公历只显示日期不显示时分
- 梅花/小六壬的「时间起卦」需要具体时辰，那两处仍用默认 12:00（那里是起卦参数，不是出生信息）
- 回归测试覆盖：不填时间可排盘、日柱不变、四柱仍齐全、真太阳时+无时辰不崩、仍能给出喜用与十神


## 十三、算法口径（重要）

工具把判断依据全部列在界面上，方便自己核对；**不做命运保证，结论请以自己取象为准**。

- **月柱以「节」为界**（立春、惊蛰…小寒），不是农历初一。节气时刻由内置历法库按天文算法计算，精确到秒。
- **日柱换日**：默认晚子时（23:00 后）算次日。
- **五行计分**：天干 1.0／字；地支按藏干本气·中气·余气比例折算，月支 ×1.5。
- **旺衰**：同党（比劫＋印）／异党（食伤＋财＋官杀）比值 ≥60% 偏强、≤40% 偏弱，其余中和——属简法。
- **六爻纳甲**依古歌：乾甲子外壬午、坎戊寅外戊申、艮丙辰外丙戌、震庚子外庚午、巽辛丑外辛未、离己卯外己酉、坤乙未外癸丑、兑丁巳外丁亥。
- **变爻六亲双标**：古书与各家软件口径不一，本工具并列显示，可按所宗之书取用。
- 详细口径见软件内 **「说明与口径」** 模块，逐条写明公式与取法。
