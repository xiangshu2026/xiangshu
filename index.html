📖 当日运势怎么看（术语小抄）
值神（黄道/黑道）
每天有一位值神当值。青龙、明堂、金匮、天德、玉堂、司命属黄道（吉）；其余六位属黑道（凶）。
建除十二神
建、除、满、平、定、执、破、危、成、收、开、闭。口诀「建满平收黑，除危定执黄，成开皆可用，闭破不相当」。
日干十神（对你）
那天的日干，相对你的日主是什么关系。印、食、比为助；官杀为压；财看身强弱。
今日之气与喜用
那天的日干五行，是否正是你的喜用神。合则天时助你，不合则做事费力。
日支冲合
那天的日支是否冲/合你的日支（你自己的"夫妻宫"）。冲主躁动易出意外，合主顺遂有人助。
冲命扣分
若日辰冲你的日支，传统叫"日辰冲命"，气势分会明显扣减（档位随之下降）。
气势分
0~100，由各项计分加权算出（50 + 合计×3.0）。档位按分位阈值由它切出，分数与档位永远一致。
📖 这个页面怎么看（术语小抄）
四柱 / 八字
年月日时各一组干支，共八个字。日柱的天干叫「日主」，代表你本人，其余七个字都围着它说话。
十神
其他干支与日主的关系名：比肩劫财（同类）、食神伤官（你生的）、正财偏财（你克的）、正官七杀（克你的）、正印偏印（生你的）。它不是神仙，是给人事关系起的名字。
藏干
地支里藏着一到三个天干，代表暗藏的力量——表面看不到、实际在起作用的那部分。
纳音
干支合成的五行别名（如「剑锋金」），多用于合婚、择日；看命主要还是看十神与旺衰。
地势
日主在这一柱上的十二长生状态（长生、沐浴、冠带、临官…），看气力处在哪个阶段。
旬空
该柱所在旬里「空掉」的两个地支。落空的力量虚，要等填实或冲空才踏实。
真太阳时
按出生地经度把钟表时间换算成当地真实的太阳时间。出生时辰卡在整点边界时才需要校正。
大运 / 流年
大运是每十年一换的大阶段，流年是每一年的干支，两者叠在原局上看当下与走势。
旺衰 / 用神
判断日主是强是弱，再找出对它有帮助的五行（用神）。本工具用「同党／异党比值」简法，只作倾向参考。

起卦方式

📖 这个页面怎么看（术语小抄）
本卦
起出来的原始卦，代表事情现在的样子与起因。
动爻
变化的那一爻，是事情的枢机。动爻在上卦还是下卦，决定了「体」和「用」谁是哪一个。
互卦
由本卦中间四爻重新组成的卦，代表事情走到中间时的局面（过程）。
变卦
动爻阴阳互换后的卦，代表事情的结果与去向。
体 / 用
动爻所在的卦为「用」（所问之事、对方），另一卦为「体」（你自己、主方）。
体用生克
用生体＝有人帮、吉；体克用＝你能掌控、吉；比和＝顺；体生用＝你在往外掏、耗；用克体＝受制、凶。
旺相休囚死
五行在当月的强弱状态：旺＞相＞休＞囚＞死。同样的卦，旺月撑得住，死月使不上劲。
应期
事情大约什么时候应验。梅花常以用卦先天数、动爻数取数，事小按日、事大按月年。

起卦

每次为一爻，自下而上装卦；背面(无字)=3，正面(有字)=2
📖 这个页面怎么看（术语小抄）
卦宫 / 卦位
六十四卦分属八宫（乾兑离震巽坎艮坤），每宫八卦各有六世、一世～五世、游魂、归魂的位置。
世 / 应
「世」代表你自己，「应」代表对方或环境。看两者生克，就知道这件事里你是主导还是受制。
纳甲
给每一爻配上天干地支（如甲子、壬午），六爻断卦的尺子全建立在这上面。
六亲
父母（长辈文书房屋）、兄弟（同辈竞争）、子孙（子女平安福气）、妻财（钱财妻子）、官鬼（官职疾病压力），由爻的五行与卦宫五行比较得出。
六神
青龙、朱雀、勾陈、腾蛇、白虎、玄武，按日干起，给事情定性质（如白虎主凶险、青龙主喜庆），属辅助。
伏神
所要的六亲在卦里不出现时，从本宫首卦借来的隐藏爻。伏神要等时机才「出伏」值事。
月建 / 日辰
起卦时的月份与日期干支。日辰管「当下」，月建管「这一个月的大势」，是判断旺衰的两把尺子。
旬空
日柱所在旬里空掉的两支。落空的爻力量虚、事情「时候未到」。
动爻 / 变爻
老阳（三背）与老阴（三正）会变，变出的爻叫变爻——变爻与动爻的生克就是事情的走向。
六冲 / 六合卦
冲主散、主快；合主聚、主缓。
游魂 / 归魂
八宫卦序里的两个特殊卦位：游魂主变动不定，归魂主回归收束。

留连

角色信息

关于「假定年份」：选它会按该年排出角色的完整八字，项目变全、分数拉得开；但年份是假的——同一角色只要换个年份，日柱就变、结论可能整档反转（实测 2026 相比月令盘，70 个角色里 44 个结论变化、最大跳动 80 分）。所以它适合当"如果 TA 生在这一年"的对照玩法，不适合当结论。年柱全体相同，年支已不计分。

角色资料有三档，知道多少算多少：
① 有完整生日（含年份） → 完整合盘（日主、日支六合六冲、日干五合、喜用/五行互补，项目最全）

③ 连月日都不知道 → 只选属性（原神看神之眼、FGO 看属性、方舟看职业印象）→ 五行简盘（最少，但总比没有强）

使用说明与算法口径

一、生辰八字

  • 月柱以「节」为界（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒），不是农历初一；节气时刻由内置历法库按天文算法给出（精确到秒）。
  • 日柱换日：默认「晚子时算次日」（流派一，23:00 后日柱进为次日）；取消勾选则 23:00 后仍按当日（流派二）。
  • 真太阳时：勾选后按「平太阳时 + 均时差 + 4分钟×(经度−120°)」校正，适合精确到时辰边界、或出生地与东八区中央经线经度差较大的情况。
  • 五行计分：天干各计 1.0；地支按藏干本气/中气/余气比例折算（0.6/0.3/0.1 等），月支×1.5 加权。
  • 旺衰：以「同党（比劫＋印）」与「异党（食伤＋财＋官杀）」比值判定，≥60% 偏强、≤40% 偏弱、其余中和。此为简法，仅供参照，不作定论。
  • 神煞按传统口诀表取（天乙贵人、文昌、禄神、羊刃、驿马、桃花、华盖、将星、孤辰寡宿、红艳、金舆、魁罡、月德天德、旬空）。各流派取法略有出入，本工具取最常见的一种。

一之二、当日运势（结合命盘）

  • 判档＝分位档：气势分先由各项规则算出，再按分位阈值切档（时辰层 65/55/36/26；日层 77/60/39/29）。目标分布 大吉5% / 吉20% / 平40% / 凶20% / 大凶15%。
  • 个人层叠加：日干对你的十神（印食比为助、官杀为压）、今日之气是否合你喜用、日支是否冲/合你日支、是否冲你年/月支、日支是否落旬空。
  • 日辰冲命扣分：若那天的日支冲你的日支，按传统「日辰冲命」在气势分里扣减（档位由分数决定）。
  • 气势分＝50 ＋ 各项合计 × 3.0（0~100），档位由分数决定，两者永远一致。
  • 十二时辰：每个时辰也有一位值神（黄道/黑道），再叠加时支与你日支的冲合、是否合喜用，排出最好/最差时辰。
  • 你没填出生时间时，只用年/月/日三柱比对（时柱不参与），结果会注明。

二、梅花易数

  • 时间起卦：上卦＝(年支数＋农历月＋日)÷8 取余，余 0 作 8；下卦＝再加时支数后÷8 取余；动爻＝该和÷6 取余，余 0 作 6。年支数子=1…亥=12。
  • 数字起卦：第一数÷8 为上卦，第二数÷8 为下卦，第三数（或前两数之和）÷6 为动爻。
  • 体用：动爻所在之卦为「用」，另一卦为「体」。用生体、体克用、比和为吉；体生用为泄；用克体为凶。
  • 互卦取本卦二三四爻为下卦、三四五爻为上卦，示事情中间过程；变卦为动爻阴阳互变后的卦，示结果。
  • 综合倾向＝体用生克 + 变卦生克 + 体卦月令旺衰加权后的经验评分，属规则式推断，供参考取象。

三、六爻（纳甲筮法）

  • 摇卦：三枚铜钱，无字面（背）为 3、有字面（正）为 2。三背＝9 老阳（动）、两背＝8 少阴、一背＝7 少阳、三正＝6 老阴（动）。
  • 装卦：依京房八宫卦序定卦宫与世应，按乾甲子外壬午、坎戊寅外戊申、艮丙辰外丙戌、震庚子外庚午、巽辛丑外辛未、离己卯外己酉、坤乙未外癸丑、兑丁巳外丁亥纳甲；六亲以卦宫五行为「我」定父母/兄弟/子孙/妻财/官鬼。
  • 六神按日干起：甲乙起青龙、丙丁起朱雀、戊起勾陈、己起腾蛇、庚辛起白虎、壬癸起玄武，自初爻向上排。
  • 伏神：六亲不上卦者，于本宫首卦同爻位寻取伏于其下。
  • 变爻六亲双标：变爻同时给出「对本宫」（以本卦卦宫为我，便于直接论生克）与「对变卦宫」（变卦自身所属宫的六亲）。两种口径古书与软件各有采用，本工具并列显示，可按所宗之书取用。

四、小六壬

  • 六宫次序：大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡；从大安起正月，月上起初一，日上起子时，数到即为落宫。
  • 三数报数：第一数从大安起，第二数从第一数落宫起，第三数从第二数落宫起。

五、今日抽卡时运（娱乐向）

  • 档位＝分位档（2026-10-20 起）：先按值神黄道/黑道 → 建除十二神（建满平收黑，除危定执黄，成开皆可用，闭破不相当）→ 吉神凶煞 → 个人十神/喜用/冲合，算出气势分；再按分位阈值切档。时辰层 65/55/36/26、日层 77/60/39/29（两层分数分布不同，各用一套）。目标分布 大吉5% / 吉20% / 平40% / 凶20% / 大凶15%。
  • 破/闭日为封顶：破日诸事不宜，即使值神是黄道也不升为吉以上；闭日封顶为平。
  • 日辰冲命扣分：若今日日支冲你的日支，按「日辰冲命诸事不宜」的传统在气势分里扣减。
  • 气势分 = 50 ＋ 合计 × 3.0（映射到 0~100），是上述各项的汇总，档位就是由它决定的；但它不是出货率预测。每一项的计分与传统依据都列在结果里。
  • 十二时辰吉凶用五个维度综合计分：时值神黄道黑道（±2）、时干对你的十神（±3）、时支五行合不合喜用（±3）、时支与你命局四支的冲合（冲日支 −8 最重）、时支与当日日支的关系。档位由综合分决定，与日层同一把尺子。
  • 档位阈值＝分位档（2026-10-20 起）：按实测分位切档，目标分布 大吉5% / 吉20% / 平40% / 凶20% / 大凶15%。分数本身（权重与烈度）不改——只调"切分标准"，不动"分数计算"。此前历史结论按旧阈值（78/64/35/22）判定，两者不可直接比较。
  • 签池按游戏独立（原神/星穹铁道/绝区零/鸣潮/明日方舟/通用），各用自己的术语；签文由「日期＋干支＋游戏＋日主」哈希确定性选取，同一天同一输入固定不变。
  • 抽卡记录与连歪计数器存在本机浏览器，不上传；「距上次出货」按记录估算（十连内出货的具体发数无法从记录得知）。
  • 每日待办提醒按当天档位、保底剩余、连歪次数、今日已抽数生成，勾选「今日已完成」后按日记录。
  • 抽卡时间建议（明写）：结果里专门有一块「今天什么时候抽最好」，直接写清最好（今日吉时，最高的那个时辰）与最差（全十二时辰最低分，必为黑道时辰），并给出各时辰的分数与值神；待办条上也带一行「最好抽／最差」。
  • 最近最宜抽卡日期：把未来 30 天逐日按同一套规则判一遍，排出最宜日（档位优先、同档比气势分、再比日期近），并给出次选日与「要避开」的最差日；最佳日还附最佳时辰。
  • 最近一周走势：今天起 7 天的档位与气势分柱状图（绿吉红凶、今天高亮），并给出本周整体走高/走低/平稳、最高日与最低日。
  • 下一发十连出卡概率（纯数学）：十连至少出一个的概率 = 1 − Π(1 − pᵢ)，pᵢ 为第 i 抽的即时概率。模型含三项参数：基础单抽概率、软保底（累计 N 抽后每抽 +x%）、硬保底（累计到 N 抽必出，概率记 100%）。参数按各游戏公示概率预填，可在界面上改成官方值（存本机）。与运势无关，别混着看。
  • 此刻抽卡（时运 × 概率）：概率态势分 = 以该游戏的基准十连概率为 50 分、保底必出为 100 分做线性归一（P10 越高分越高，0 累计时正好 50）；综合抽卡分 = 时运分 × 50% ＋ 概率态势分 × 50%。公式与两个分项都直接印在结果里。档位（大吉/吉/平/凶/大凶）仍只由传统择日规则判定，不含概率分。
  • 本期卡池 · 哪天抽最好：填卡池起止日期，把剩余每一天逐日判一遍，给出区间内最宜日（含最佳时辰与建除）、避开日、次选日、区间档位分布，以及 76 天这种逐日色带一览；并会比较今天与最佳日，直接说「今天先别抽、等到 X 月 X 日」。
  • 什么会变、什么不会变：档位与气势分只由当日历法决定，换游戏、换账号都不会改变它；游戏只决定签池，账号只决定签文（按「日期＋账号＋游戏」定签）。切换游戏或修改账号名会即时重算，不需要再点按钮。

六、时辰未知的处理

  • 出生时间默认留空，不记得就别填——程序不会按正午 12:00 或子时去"假装知道"。
  • 不填时间时：时柱标记为「未知」，且不参与身强身弱的得地/得势判断（缺一柱就不拿它当依据）。
  • 年柱、月柱、日柱不受时间影响（日柱只由日期决定），所以十神、喜用神、大运、五行强弱照样算得出来。
  • 结果里「时辰」显示为「未填（不做时柱判断）」，公历只显示日期、不显示时分。
  • 梅花易数 / 小六壬的「时间起卦」是起卦参数不是出生信息，那两处仍用默认 12:00。

七、二次元相性（娱乐向）

  • 方法：按传统合盘（合婚/合盘）规则比对双方八字，不靠随机数。比对项：日主五行生克、日支（夫妻宫）六合/三合/六冲、日干五合、日柱天克地冲、喜用神互补、五行互补（我缺是否他旺）、年支六合/六冲。
  • 计分：相性分 = 50 ＋ 各项合计（clamp 0~100）。各项分值固定且公示在结果表里：日主"他生我 +20 / 我生他 +14 / 同 +10 / 我克他 −10 / 他克我 −18"；日支"六合 +16 / 三合 +12 / 同支 +6 / 六冲 −22"；日干五合 +14；天克地冲 −12；喜用互补各 +10；五行互补每项 +8（最多 16）；年支六合 +6 / 六冲 −8。
  • 分数归一（重要）：50 分 = 中性（各项合计 0）；100 分 = 该档位理论满分。三档满分不同——完整盘 100、月令盘 88、简盘 80（资料越少，能判断的维度越少，上限按信息量打折，避免"选项少反而虚高"）。等级线统一：≥88 天作之合 / ≥76 相得益彰 / ≥62 平顺相处 / ≥46 需要磨合 / 其余八字相冲。所以月令盘 79 分已属高分，想上 88 需要角色的完整生日（含年份）。同档位内分数容易并列，是因为月令盘只有 2 个计分项，这是资料本身的信息量上限，不是算法偷懒。
  • 等级：按分数固定区间（≥88 天作之合 / ≥76 相得益彰 / ≥62 平顺相处 / ≥46 需要磨合 / 其余八字相冲），不是另调权重。
  • 角色信息三档：① 完整生日（含年份）→ 完整合盘；② 只知道月/日 → 月令盘：用节气月定角色「月令」（八字里最重的一层，代表先天气质与底色），可比日主生克、我的月支与该月令的六合/三合/六冲、喜忌、补缺；节气交界（年份不同差±1天）会提示「可能是 X 月或 Y 月」；③ 连月日都不知道 → 只选属性 → 五行简盘：日主生克 + 十神关系 + 属性类象 + 喜忌 + 补缺。
  • 游戏属性 → 五行换算（依八卦类象）：风→木（巽为风）、雷→木（震为雷）、草→木、冰→水、暗→水（坎为隐伏）、光→火、电→火（离为电）、岩→土（艮为山）、金→金。结果里会写明换算依据。
  • 月令盘与完整盘的区别：月令只用了「月」这一层，年柱、日柱（日主）、时柱都缺，所以分项少、置信度标注为「中等」；完整盘才有日支、日干、时柱这些。分数权重也相应减半（月令盘：日主生克 ±10/+7/+5/−5/−9，月令合冲 六合+10/三合+8/同+4/六冲−14，喜用+6、忌−5、补缺+5）。
  • 内置名单：收录 79 名女性角色（绝区零全量 41 / 原神 12 / 崩铁 10 / FGO 8 / 方舟 8），带属性、生日（月/日）、特性，点名字自动填入。属性与生日取游戏官方设定（2026-10 逐条核对）；3.x 新属性（玄墨/凛刃/流明/风/烈霜）与以太、物理、量子、盾的五行换算属本软件约定，无传统定论。
  • 角色库：填过的角色可「存到角色库」，本机保存（名字/属性/月日/生日），点 chip 一键填回，✕ 可删。
  • 定位：角色是虚构的，合盘娱乐为主；分数只说明"气场结构"，不构成对现实关系的判断。

八、界面结构

  • 首页只有 6 个模块卡片；点进去只看该模块，左上角返回。抽卡时运内部再分为「今日时运 / 最近最宜 & 一周走势 / 卡池档期 / 抽卡记录 & 十连概率 / 术语小抄」5 个子模块。
  • 地址栏支持 #hash 直达（如 #gacha、#bazi），刷新后仍停在该模块。

九、免责与定位

本工具是传统术数的排盘与规则推演工具，负责把干支、卦象、装卦、生克按古法准确摆出来，并把判断依据列清（便于自己核对）。它不做命运保证，也不替代用户的判断——同一卦，取象与经验不同，结论自然不同。
